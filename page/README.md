# 飞羽科技 · HR 智能助理 前端

基于 `api.py` 接口构建的现代化聊天前端，纯原生 HTML / CSS / JavaScript，无构建步骤、无外部依赖。

## 目录结构

```
page/
├── index.html        # 页面结构（侧边栏 + 聊天区 + 输入区）
├── css/
│   └── style.css     # 样式（设计令牌、布局、组件、响应式）
├── js/
│   └── app.js        # 前端逻辑（SSE 解析、台账渲染、markdown、校验）
└── README.md
```

## 快速开始

### 1. 启动后端（必需）

```bash
# 在项目根目录
python -m uvicorn api:app --host 127.0.0.1 --port 8000 --workers 1
```

> 注意：`InMemorySaver` 记忆与 SQLite 连接均为进程内状态，**必须单 worker 运行**。

后端已配置 CORS（`api.py` 中 `CORSMiddleware`），允许前端跨域调用。

### 2. 启动前端

任选其一：

```bash
# 方式 A：静态文件服务器（推荐）
cd page
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080

# 方式 B：直接双击打开 index.html（file:// 协议亦可，CORS 已放开）
```

### 3. 配置 API 地址（可选）

默认后端地址为 `http://127.0.0.1:8000`。若后端部署在其他地址，可在浏览器控制台设置：

```js
localStorage.setItem("hr_agent_api_base", "http://your-host:8000");
```

## 对接的接口

| 方法 | 路径 | 用途 | 前端对应 |
| --- | --- | --- | --- |
| `POST` | `/chat` | SSE 流式聊天 | 发送提问，逐帧渲染工具过程与答复 |
| `GET` | `/health` | 健康检查 | 侧边栏「服务在线」状态灯（30s 轮询 + 手动点击重试） |

### SSE 帧协议（`app.js` 中的 `handleFrame` 处理）

| `type` | 含义 | 前端处理 |
| --- | --- | --- |
| `tool_call` | Agent 即将调用工具 | 台账新增「执行中」步骤 |
| `tool_result` | 工具返回摘要 | 对应步骤标记「完成」+ 摘要 |
| `answer` | 最终答复（含审计重写） | 渲染 markdown 答复；再次到达时提示「已重写」 |
| `error` | 异常 | 显示红色错误气泡 |
| `done` | 结束帧 | 收尾清理 |

## 功能清单

- **流式对话**：基于 `fetch` + `ReadableStream` 解析 SSE（`POST /chat` 不能用 `EventSource`）。
- **处理过程台账（签名设计）**：将 Agent 的 `tool_call` / `tool_result` 渲染成带状态灯的时间线，直观展示「查档案 → 查假期 → 审计」的执行过程，透明可信。
- **审计重写提示**：当答复被合规审计打回重写时，自动显示「已根据合规审计意见重写答复」。
- **Markdown 渲染**：安全的轻量渲染器（先转义，支持标题 / 列表 / 引用 / 代码块 / 行内代码 / 加粗 / 链接）。
- **连接状态**：`/health` 健康检查，绿 / 红状态灯，断连时聊天框给出明确错误提示。
- **会话管理**：`thread_id` 记忆共享，一键「新建会话」清空上下文。
- **员工 UID 校验**：必填，本地持久化（`localStorage`）。
- **快捷提问**：侧边栏示例问题一键发起。
- **响应式布局**：桌面双栏；≤860px 时侧边栏收为抽屉（汉堡按钮 + 遮罩）。
- **无障碍与体验**：键盘焦点可见、`prefers-reduced-motion` 尊重减少动效、Toast 反馈、发送中禁用输入。

## 设计说明

- **配色**：冷调 sage 纸面（`#f3f5f0`）+ 松柏绿主色（`#146b5a`）+ 朱砂印章红（`#c14e36`，仅用于审计 / 错误，呼应「公章」意象）。
- **字体**：品牌与标题用宋体（公文 / 证书质感），正文用系统无衬线，UID / 会话 ID / 工具名用等宽字体（台账 / 操作台质感）。
- **签名元素**：处理过程台账 —— 把 Agent 的推理步骤可视化为一条「审计台账」，是本产品（事实校验型 HR 助理）区别于普通聊天机器人的记忆点。
